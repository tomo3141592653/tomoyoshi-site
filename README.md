# ひらたともよし！ (モダン版)

https://sites.google.com/site/hiratatomogi/ を静的サイトとして再構築したもの。

- 全111ページをクロールし、本文・画像(111枚)を抽出して生成
- 純粋な静的HTML+CSS。ビルドツール・JSフレームワーク不要
- レスポンシブ、ダークモード対応(prefers-color-scheme)

## 構成

- `index.html` — トップ(4セクションのカード+SNSリンク)
- `mywork/` — つくったもの(日記2002-2006、文集、物理ノート、素数の歌など)
- `favorites/` — おきにいり(平田書店、映画、サイトなど)
- `aboutme/` — じこしょうかい(略歴、履歴書、健康など)
- `announce/` — おしらせ(自由研究発表会マイクロなど)
- `assets/` — 画像

## 公開方法

このフォルダをそのままGitHub Pages / Vercel / Netlify等に置けば動く。
例: GitHubリポジトリにpushして Settings → Pages → Deploy from branch。

## 再生成

生成スクリプトは ayumu-lab/research/tomoyoshi-site-2026/ にある:
1. `python3 crawl.py` — 元サイトをクロール(raw/へ保存)
2. `python3 build.py` — 本文抽出(pages_full.json)
3. `python3 fetch_images2.py` — 画像回収(agent-browser経由)
4. `python3 render.py` — このフォルダにHTML生成
